# خان هشتم — سند طراحی بازی (سایت)

سایت ایستای سند طراحی بازی «خان هشتم»، منتشرشده روی GitHub Pages:

- سایت: https://macsword.github.io/eighth-khan-gdd/
- مخزن: https://github.com/macsword/eighth-khan-gdd

## ساختار

| فایل | نقش |
|---|---|
| `gdd_fa.md` | **منبع محتوا** (Markdown فارسی؛ سند زنده همین فایل است) |
| `build.py` | تبدیل `gdd_fa.md` + `template.html` به `index.html` |
| `template.html` | قالب صفحه (سربرگ، فهرست کشویی، پانویس) |
| `style.css` | ظاهر (موبایل‌اول، RTL، روشن/تیره، چاپ) |
| `app.js` | فهرست کشویی، برجسته‌سازی بخش جاری، راهنمای اسکرول جدول |
| `index.html` | خروجی ساخته‌شده (همین را GitHub Pages نشان می‌دهد) |
| `.nojekyll` | جلوگیری از پردازش Jekyll |
| `shoot.js` | (اختیاری) اسکرین‌شات و بررسی با Chrome بی‌سر |

فونت: Vazirmatn از Google Fonts (رایگان، OFL).

## به‌روزرسانی

```bash
cd /workspace/gdd-site
# 1) gdd_fa.md را ویرایش کنید
TZ=Europe/Berlin python3 build.py   # بدون --date، تاریخ امروز شمسی گذاشته می‌شود (ساعت جعبه UTC است)
git add -A && git commit -m "به‌روزرسانی سند" && git push
# GitHub Pages ظرف ۱ تا ۲ دقیقه به‌روز می‌شود
```

نیاز: Python 3 با بسته‌ی `markdown` (`pip install markdown`).

### قواعد Markdown پشتیبانی‌شده
- `# عنوان` (خط اول) = عنوان صفحه؛ `## ۱. …` = بخش شماره‌دار (شناسه‌ی `#s1` تا `#s22`)؛ `### …` = زیربخش.
- جدول‌های `| … |`، فهرست‌های `-` و `1.` (زیرفهرست با دو فاصله)، `**پررنگ**`، `` `کد` ``، بلوک ```` ``` ````، نقل‌قول `>`.
- فهرست داخل بخش «فهرست» خودکار به بخش‌ها پیوند می‌شود؛ فهرست کناری از سرتیترها ساخته می‌شود.
- جدول‌های ۵ ستون یا بیشتر بدون شکستن خط و با اسکرول افقی نمایش داده می‌شوند.

### بررسی (اختیاری)
```bash
python3 -m http.server 8765 &   # در همین پوشه
node shoot.js http://localhost:8765/   # shot_mobile.png / shot_desktop.png + بررسی سرریز، تعداد بخش‌ها و جدول‌ها، فونت
```
`shoot.js` از puppeteer-core در `/workspace/ekbuild/node_modules` و `/usr/bin/google-chrome` استفاده می‌کند.
